
# CYVORA Security Policy

## Security Principles

CYVORA follows secure development practices
throughout its development lifecycle.

## Reporting Security Issues

Team members must report suspected vulnerabilities
to the project technical lead privately.

Do not publish sensitive vulnerability details
in public discussions.

## Security Requirements

- Protect API keys and credentials.
- Enforce appropriate access controls.
- Validate user input.
- Use secure authentication practices.
- Avoid exposing sensitive information in logs.
- Use synthetic datasets during development.

## Testing

Security testing must be authorised and performed
in controlled environments.

## Status

This policy applies during the development
of the CYVORA platform.
